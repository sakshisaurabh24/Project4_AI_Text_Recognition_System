# Project4_AI_Text_Recognition_System

## Overview

This project demonstrates a simple AI Text Recognition System developed using Python. The system accepts text input from the user and performs basic text analysis.

## Technologies Used

- Python
- Google Colab

## Features

- Accepts user text input
- Displays entered text
- Counts total words
- Counts total characters
- Converts text to uppercase
- Converts text to lowercase
- Simple and beginner-friendly implementation

## How to Run

1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run all cells.
3. Enter any text when prompted.
4. View the analysis results.

## Sample Output

Input:
Python is my favorite programming language

Output:
- Total Words: 6
- Total Characters: 42
- Uppercase Text
- Lowercase Text
